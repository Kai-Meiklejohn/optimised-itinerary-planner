# Contributing

Open an issue to discuss a change, then submit a focused pull request with relevant tests. Follow the [README](README.md) to install dependencies and run all checks before requesting review.

Use your own AWS development resources for manual testing. Automated tests must work without real credentials or network access to AWS. Do not include deployment URLs, account details, environment files, Terraform state, customer data or live keys in commits or screenshots.

Contributions are provided under the project's MIT licence. Keep changes small and explain the user-visible behaviour and how you tested it.
